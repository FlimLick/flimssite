Beta
Security note: direct P2P via STUN with MQTT signaling. The room password derives the signaling channel and is never sent. The host relays messages for the room. Only share room codes with people you trust and avoid sensitive data.
How to connect
  1. Pick a room code and share it with your group.
  2. Set a room password on every device.
  3. Host clicks Host room. Joiner clicks Join room.
  4. Offers, answers, and ICE candidates exchange automatically.
  5. Host stays open so everyone can keep chatting.
  6. Use Disconnect to reset and try again.
Everyone connects to the host through WebRTC. The host forwards messages to the room.
